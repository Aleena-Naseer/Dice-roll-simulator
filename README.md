# Dice Roller
A simple Python command-line program that simulates rolling two six-sided dice.
## Features
- Roll two dice
- Display the total
- Roll multiple times
- Handle invalid input
## Technologies
- Python
- Random module
- Functions
- Loops
- Conditional statements
## How to Run 
```bash
git clone https://github.com/your-username/dice-roller.git
cd dice-roller
python dice_roller.py
